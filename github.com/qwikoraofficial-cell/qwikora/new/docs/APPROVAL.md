المعتمد نهائيًا
الوعد v4 + حظر صيغ التفوق + content-lint (مع التطبيع والإنجليزية)
الهوية: استوديو الذكاء الخاص — بلا «رائد/نقلة» في أي نص عام حتى و-7
الوحدة المقررة: data-chat (DC-1..DC-8) — المؤرشفون: ai-redact/doc-extract/photo-search (تفعيل بقياس) — omni-search موقوفة حتى حسم الترخيص الجذري
أرضية الإطلاق: 3 وحدات مؤهلة أو لا إطلاق باسم استوديو + نقطة قرار نهاية المرحلة 4
T5 v2 (تجميد قبل البحث + فاحص مستقل) + السجل السالب المؤرخ
S0 في المرحلة 2.5 قبل المحرك: Qwen3.5-2B + Qwen2.5-Coder-0.5B (توثيق جذري لكل منهما قبل أي تنزيل — تحذير 3B مسجل) — تبديل + ذاكرة ≤110% + ذروة ≤3GB + سيناريو كامل (1M صف + سؤالان)
ترتيب المراحل المعدل: 0→1→2(+حماية دنيا+_headers+قرار المضيف)→2.5(S0)→3→4أ(نواة الإثبات)→4ب(data-chat + T5/G6 للمؤرشفة بالتوازي)→نقطة قرار الأرضية→5→6→7(+بروفة release)
الأمان: enable_external_access=false مقفول + CSP مرجع أول + SW كاشف/مسجل + WebRTC في G5 + نص اللوحة معدل + COOP/COEP (R5)
الاستضافة: HF أساسي + مرآة موثقة + شرائح ≤20MB + SBOM لكل شريحة + GitHub Actions للبناء + رفع مباشر للنشر
verify:gates يربط كل سجل بـcommit SHA + hash النموذج + إصدار المحرك
الميزانيات بمقام موحد (budgets.json) + إطار خفيف + المحركات dynamic import + قياس الخطوط مبكرًا
CSV حتى 1M + Excel بحد مقاس معلن
R10 بالخطر لا بالأسطر + بطاقة قرار بأدلة آلية للاعتماد البشري
المؤجل: لوحة الأوامر، Scorecard، تجربة تثبيت PWA / المحذوف: التقرير الطائر
فشل نقاط الفشل الصامتة الثلاث: تنزيل النموذج الحقيقي قبل كل إصدار + G5 ببروفيل نظيف + بروفة kill-switch
ما أقره كلود «سليم» دون تغيير (R1,R2,R4,R6,R7,R11,R12، دورة الحياة، CI ثلاثي، G6 المجمد، ضوابط التوريد، الفشل المشترك)
